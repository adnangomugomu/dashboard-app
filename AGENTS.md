# Workflow

- Setelah **selesai mengerjakan setiap tugas**, jalankan `git push origin`
  (branch `main`).
- Setelah selesai mengerjakan tugas, **perbarui index codebase-memory MCP**
  untuk projek ini (`index_repository` dengan `repo_path` root projek).
- Pastikan working tree sudah di-commit sebelum push.

# Projek

ADNANDEV-APP — aplikasi desktop Linux (Electron) untuk mengelola service projek,
command Linux, dan monitoring `btop`.
